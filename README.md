# astrbot_plugin_weather · 天气查询

在 AstrBot 里发一句 `/天气 北京`，就能拿到当地今天的天气。

数据来自 [Open-Meteo](https://open-meteo.com)，**完全免费、无需注册、无需 API Key**。

## 功能

| 指令 | 说明 |
| --- | --- |
| `/天气 地点` | 查询该地点今天的天气 + 未来 3 天预报 |
| `/天气 39.9,116.4` | 直接用经纬度查询 |
| `/天气帮助` | 查看使用说明 |

返回内容包含：当前温度与体感温度、天气现象、湿度、风向风力、今日最高/最低温、降水概率、紫外线指数、日出日落时间，以及未来 3 天（明天起）的天气、温度区间和降水概率。

未来天数可通过 `forecast_days` 配置（0 关闭，最多 7 天）。

## 安装

1. 把 `astrbot_plugin_weather` 文件夹放进 AstrBot 的 `data/plugins/`：

   ```
   AstrBot/
   └── data/
       └── plugins/
           └── astrbot_plugin_weather/
               ├── main.py
               ├── metadata.yaml
               ├── _conf_schema.json
               └── requirements.txt
   ```

2. 在 WebUI「插件管理」里重载插件，或重启 AstrBot。
3. 依赖只有 `aiohttp`（AstrBot 自带），无需额外安装。

## 配置项

| 配置 | 默认 | 说明 |
| --- | --- | --- |
| `default_city` | 空 | 不带地点时默认查询的城市，留空则提示用法 |
| `forecast_days` | 3 | 未来预报天数（0 关闭，最多 7） |
| `language` | zh | 地名语言，`zh` / `en` |
| `cache_minutes` | 10 | 同地点天气缓存时长，0 为不缓存 |
| `geo_count` | 5 | 同名地点候选数 |
| `show_source` | true | 是否显示「数据来源」 |
| `show_alternatives` | true | 是否附「也可以查」同名地点提示 |
| `timeout` | 10 | 请求超时（秒） |

## 数据来源

- 地理编码：`https://geocoding-api.open-meteo.com/v1/search`（把地名转成经纬度）
- 天气预报：`https://api.open-meteo.com/v1/forecast`（`timezone=auto`，按当地时区取「今天」；`forecast_days=N+1` 一次拿到今天和未来 N 天）

天气现象使用 WMO 天气代码，插件内置了中文对照表（晴 / 多云 / 阴 / 雾 / 小雨 / 雷阵雨 / 大雪 …）。

## 注意事项

- **地名库有限**：Open-Meteo 的地理编码基于 GeoNames，中国的小乡镇可能查不到。查不到时试试加省市，比如「浙江义乌」。
- **国外城市**：中文译名在 GeoNames 里经常缺失或指向同名小村庄（「纽约」查不到、「东京」会命中江苏的同名村）。插件内置了 50 多个常用国外城市的中文→英文别名表（东京 / 纽约 / 伦敦 / 首尔 / 巴黎 / 悉尼 …），会自动转换后再查。表里没有的城市，直接用英文名更准，比如 `/天气 Reykjavik`。
- **同名地点**：像「朝阳」这种重名较多的地方，插件会在候选里优先选人口较多的那个，返回末尾附上其他同名地点供参考，可以加省份精确查询（如 `/天气 山西朝阳`）。
- **时区**：请求带 `timezone=auto`，国外城市也会按当地时间返回当天数据。
- **免费额度**：Open-Meteo 免费版限制约 1 万次/天、600 次/分钟，个人使用绰绰有余。插件内置了地理编码 24 小时缓存和天气短时缓存，进一步减少请求。
